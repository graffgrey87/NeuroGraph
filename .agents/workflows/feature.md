---
description: Стандартный процесс добавления новой функции в проект
---
1. Проанализируй запрос на добавление новой функции.
2. Проверь `docs/TODO.md` на наличие связанных задач (если есть - удали из TODO после реализации).
3. Изучи `docs/Changelog.md` и `README.md` для понимания контекста без глубокого погружения во весь код.
4. Выполни реализацию (добавь код, обнови UI и т.д.).
5. Зафиксируй изменения в `docs/Changelog.md`, добавив запись: `- Добавить: [суть функции]`.
6. Обнови `install.sh`, если потребовались новые библиотеки.
