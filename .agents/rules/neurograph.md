Анализ базы знаний: Перед выполнением любой задачи по изменению кода или добавлению функций обязательно проверяй содержимое папки docs/ для соблюдения контекста проекта.

Ведение Changelog: После каждого исправления багов (fix) или внедрения новой функции (feature) обновляй файл docs/Changelog.md. Записи должны быть краткими, в повелительном наклонении (например, «Исправить ошибку...», «Добавить модуль...»).

Обновление планов (TODO): Все нереализованные идеи или задачи, возникшие в процессе работы, должны заноситься в docs/TODO.md. Если задача выполнена, она переносится в Changelog и удаляется из TODO.

Артефакты: Используй систему артефактов Antigravity для демонстрации планов изменений и диффов кода перед их окончательным применением.
