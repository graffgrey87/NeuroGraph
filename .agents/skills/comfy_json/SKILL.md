# Использование навыка ComfyUI JSON Editor

Большие файлы рабочих процессов тратят очень много токенов при их чтении или записи целиком. Для экономии лимитов всегда используй скрипт `update_json.py`.

## Строгое правило:
1. **НЕ читай и НЕ перезаписывай** большие JSON-файлы воркфлоу целиком с помощью стандартных инструментов (`view_file`, `replace_file_content`).
2. Используй скрипт `update_json.py` для точечной правки значений через терминальную команду.
3. Аргументы: `python <путь к update_json.py> <путь к json> <ID_ноды> <имя_параметра> <значение>`

Пример (изменить сид у ноды 7):
```bash
python f:\Neuro_Graph\NeuroGraph\.agents\skills\comfy_json\update_json.py f:\Neuro_Graph\NeuroGraph\workflow_api.json 7 seed 123456789
```
