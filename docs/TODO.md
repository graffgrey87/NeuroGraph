# NeuroGraph — TODO / Roadmap

## Приоритет: Средний

### 1. Прогресс генерации в реальном времени
**Проблема:** Статусное сообщение показывает только номер batch, но не прогресс steps внутри одной генерации.
**Решение:** Подключиться к WebSocket ComfyUI (`ws://127.0.0.1:3000/ws?clientId=...`), слушать events `progress` (step/total). Обновлять статусное сообщение с % завершения.

### 2. Галерея последних результатов
**Проблема:** Результаты генерации видны только в чате. Нет способа быстро пролистать историю.
**Решение:** Кнопка "📁 История" — отправляет последние N результатов как альбом (InputMediaPhoto). Хранить список путей к файлам в user_data.

### 3. Пресеты настроек (Flux)
**Проблема:** Каждый раз нужно настраивать Пульт заново (камера, лоры, промпт). Нет быстрого переключения между наборами.
**Решение:** Кнопка "💾 Сохранить пресет" в WebApp. Данные сохраняются как именованные конфигурации. В боте — кнопка "📋 Пресеты" со списком для быстрой загрузки.

### 4. Превью референсов в WebApp (Пульт Flux)
**Проблема:** В WebApp при выборе референсов видно только имя файла в `<select>`. Чтобы вспомнить какая картинка — нужно листать чат.
**Решение:** Миниатюры в WebApp рядом с каждым слотом Reference. При выборе файла — подгрузка превью через `webapp_server.py` (эндпоинт `/api/preview?file=имя.jpg`).
**Альтернатива:** Прямой URL ComfyUI `/view?filename=...&type=input` через RunPod proxy.

### 5. Dataset naming с авто-нумерацией
**Проблема:** Кнопка "Имя сета" задаёт статичный префикс. При batch все файлы получают одинаковое имя.
**Решение:** Автоматическая нумерация: `SetName_001`, `SetName_002`. Через ноду 211 передавать `{name}_{counter}`.

### 6. Проверка здоровья ComfyUI перед генерацией
**Проблема:** Если ComfyUI упал или перегружен, бот отправляет workflow и висит в ожидании.
**Решение:** Перед queue_prompt делать `GET /system_stats`. Если не отвечает — сообщить пользователю сразу.

## Приоритет: Низкий (Quality of Life)

### 7. Уведомление об окончании batch
**Проблема:** При большом batch (10+) неудобно ждать у экрана.
**Решение:** Финальное сообщение "🏁 Batch 10/10 готов за 4m 32s".

### 8. VRAM мониторинг
**Проблема:** При 5+ референсах возможно переполнение VRAM.
**Решение:** Предупреждение при >3 активных референсах. Или `/system_stats` для проверки.

### 9. Wildcard-парсер в боте
**Проблема:** Файлы wildcards используются только ComfyUI нодами. Бот не может подставить рандомные значения до отправки.
**Решение:** Парсер, заменяющий `__действие__` на случайную строку из `wildcards/действие.txt`.

### 10. Веб-панель статуса
**Проблема:** Нет единого дашборда: что генерируется, сколько в очереди, статус ComfyUI.
**Решение:** Расширить webapp_server.py — страница /status с данными от `/queue` и `/system_stats`.

### 11. Автоочистка старых input-изображений
**Проблема:** Каждая загрузка фото через бота создаёт файл в ComfyUI/input. Со временем накапливаются гигабайты.
**Решение:** Cron-задача или команда бота для удаления файлов старше N дней.
