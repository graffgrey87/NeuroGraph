## Приоритет: Высокий

### 1. Ускорение загрузки моделей (install.sh)
**Проблема:** wget качает файлы по одному, однопоточно. ~30 файлов включая модели 9GB+.
**Решение:** Заменить wget на aria2c (многопоточная загрузка, x16 connections). Мелкие файлы (лоры) качать параллельно пачками.
**Ожидаемый эффект:** Сокращение времени установки в 3-5 раз.

### 2. Сохранение user_data на диск
**Проблема:** Все настройки пользователей (flux_store, lora-миксы, batch, mode) живут в RAM. При перезапуске бота или пода — теряются.
**Решение:** Сохранять user_data в JSON-файл (/workspace/user_data.json). Загружать при старте, записывать при изменениях (debounce).
**Сложность:** Низкая. Не затрагивает логику, только I/O при старте и после ключевых действий.

### 3. Таймаут генерации
**Проблема:** Если ComfyUI зависает, run_workflow крутит `while True: get_history()` бесконечно. Бот не отвечает.
**Решение:** Добавить таймаут (например 300 секунд). При превышении — отправить ошибку пользователю, освободить управление.

### 4. Отмена генерации
**Проблема:** Нет способа остановить batch или текущую генерацию из Telegram.
**Решение:** Кнопка "⛔ СТОП" в статусном сообщении (inline). При нажатии — отправить /interrupt в ComfyUI API + прервать цикл batch.
**API:** `POST http://127.0.0.1:3000/interrupt`

## Приоритет: Средний

### 5. Прогресс генерации в реальном времени
**Проблема:** Статусное сообщение показывает только номер batch, но не прогресс steps внутри одной генерации.
**Решение:** Подключиться к WebSocket ComfyUI (`ws://127.0.0.1:3000/ws?clientId=...`), слушать events `progress` (step/total). Обновлять статусное сообщение с % завершения.

### 6. Галерея последних результатов
**Проблема:** Результаты генерации видны только в чате. Нет способа быстро пролистать историю.
**Решение:** Кнопка "📁 История" — отправляет последние N результатов как альбом (InputMediaPhoto). Хранить список путей к файлам в user_data.

### 7. Пресеты настроек (Flux)
**Проблема:** Каждый раз нужно настраивать Пульт заново (камера, лоры, промпт). Нет быстрого переключения между наборами.
**Решение:** Кнопка "💾 Сохранить пресет" в WebApp. Данные сохраняются как именованные конфигурации. В боте — кнопка "📋 Пресеты" со списком для быстрой загрузки.

### 8. Превью референсов в WebApp (Пульт Flux)
**Проблема:** В WebApp при выборе референсов видно только имя файла в `<select>`. Чтобы вспомнить какая картинка в каком слоте — нужно листать чат бота и искать превью среди сообщений. При 4-6 активных рефах это крайне неудобно.
**Решение:** Добавить миниатюры (thumbnails) прямо в WebApp рядом с каждым слотом Reference. При выборе файла в `<select>` — подгружать превью через `webapp_server.py` (эндпоинт `/api/preview?file=имя.jpg`). Сервер отдаёт уменьшенную копию из ComfyUI/input. Миниатюра отображается как `<img>` внутри `.ref-card`.
**Альтернатива:** Если не усложнять сервер — использовать прямой URL ComfyUI `/view?filename=...&type=input` через RunPod proxy.

### 9. Dataset naming с авто-нумерацией
**Проблема:** Кнопка "Имя сета" задаёт статичный префикс. При batch все файлы получают одинаковое имя.
**Решение:** Добавить автоматическую нумерацию: `SetName_001`, `SetName_002` и т.д. Через ноду 211 передавать `{name}_{counter}`.

### 10. Проверка здоровья ComfyUI перед генерацией
**Проблема:** Если ComfyUI упал или перегружен, бот отправляет workflow и висит в ожидании.
**Решение:** Перед queue_prompt делать `GET /system_stats`. Если не отвечает — сообщить пользователю сразу, не ставить в очередь.

## Приоритет: Низкий (Quality of Life)

### 11. Уведомление об окончании batch
**Проблема:** При большом batch (10+) неудобно ждать у экрана.
**Решение:** После завершения всего batch — звуковое уведомление через Telegram (или просто финальное сообщение "🏁 Batch 10/10 готов за 4m 32s").

### 12. Копирование seed из результата
**Проблема:** Если понравился результат, нет способа быстро узнать seed для повторения.
**Решение:** Добавить seed в caption результата. Или inline-кнопку "🔁 Повторить с этим seed".

### 13. VRAM мониторинг
**Проблема:** При 5+ референсах возможно переполнение VRAM. Узнать об этом можно только по крэшу.
**Решение:** Перед генерацией с >3 активными референсами — предупреждение. Или запрос `/system_stats` для проверки свободной VRAM.

### 14. Wildcard-парсер в боте
**Проблема:** Файлы wildcards (18 шт.) используются только ComfyUI нодами. Бот не может подставить рандомные значения в шаблон до отправки.
**Решение:** Парсер, заменяющий `__действие__` на случайную строку из `wildcards/действие.txt`. Позволит видеть реальный промпт до генерации.

### 15. Веб-панель статуса
**Проблема:** Нет единого дашборда: что сейчас генерируется, сколько в очереди, статус ComfyUI.
**Решение:** Расширить webapp_server.py — добавить страницу /status с информацией от ComfyUI `/queue` и `/system_stats`.

### 16. Автоочистка старых input-изображений
**Проблема:** Каждая загрузка фото через бота создаёт файл в ComfyUI/input. Со временем накапливаются гигабайты.
**Решение:** Cron-задача или команда бота для удаления файлов старше N дней из input/.
